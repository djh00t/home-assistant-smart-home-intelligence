# Support

## Usage Help

Use GitHub issues for:

- install problems
- configuration questions
- runtime behavior bugs
- feature requests

## Before Opening an Issue

- confirm the repository README and HACS install steps
- run the latest tagged release or current `main`
- gather relevant Home Assistant version, install method, and redacted logs

## Security

For vulnerabilities, follow [SECURITY.md](SECURITY.md). Do not open public issues for sensitive reports.

## Scope Boundaries

This repository covers the Home Assistant integration and its contracts.

External systems such as Frigate, Jetson, ANPR, and face-recognition providers are upstream dependencies and may need debugging in their own environments.
